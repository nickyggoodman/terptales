# terptales

## Highlights
* Add books in epub and pdf format from device and external link
* Annotate pages
* Flip through pages using phone gyroscope

## Overview
Terptales was created as a part of a semester-long group project for 
Dr. Michael Marsh's mobile applications course. The application is built using
for mobile Android devices using the Flutter framework. The purpose of the app
is to create an an ereader that feels more like "real" book and can pull from 
a diverse set of sites using epub and pdf formats.
